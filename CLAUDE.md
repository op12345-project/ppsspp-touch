# Claude Code instructions for PPSSPP Touch

Follow the repository instructions in [AGENTS.md](AGENTS.md), including its existing PPSSPP
build, testing, safety, and commit rules. Use [docs/CURRENT_STATE.md](docs/CURRENT_STATE.md) as
the shared handoff with Codex. Read it at the start of each task, then check `git status` and
recent commits. The current code and Git history take precedence over stale documentation.

After a meaningful completed task, record actual changes, tests run, unresolved issues, and the
next action in `docs/CURRENT_STATE.md`. Change [docs/ROADMAP.md](docs/ROADMAP.md) or
[docs/DECISIONS.md](docs/DECISIONS.md) only when necessary. Keep notes concise, do not claim
unrun tests passed, and do not overwrite another agent's uncommitted work.
